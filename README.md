# WhatsApp GIF Sender

WhatsApp Web still doesn't let you upload GIFs properly. If you drag a GIF into the browser, it gets sent as a static frame instead of a looping GIF.

This extension fixes that.

Drop a `.gif` directly into a WhatsApp chat, or use the upload button in the bottom-right corner to select GIF, WebP, APNG, MP4, WebM or MOV files. The extension converts the file into the format WhatsApp expects, applies the correct GIF metadata, and inserts it into WhatsApp's normal upload flow. From there, you can preview and send it exactly as you normally would.

The goal is simple: make sending GIFs on WhatsApp Web work the way it should have in the first place.

### Everything stays on your PC

All processing happens locally in your browser. Your files are never uploaded to a server, sent to a third party, or leave your computer at any point.

Video conversion is performed using your own hardware, so for the best experience you'll want browser hardware acceleration enabled with H.264 encoding support. This keeps conversions fast while ensuring everything remains completely local.

### Features

* Drag and drop `.gif` files straight into a WhatsApp chat.
* Upload GIF, WebP, APNG, MP4, WebM and MOV files from the built-in panel.
* Automatically converts supported formats into WhatsApp-compatible looping GIFs.
* Uses WhatsApp's own send preview, Nothing is sent automatically.
* No accounts, no cloud processing, no data collection.
